# Omnisのコンセプトとケース試作メモ

自宅でもオフィスでも、普段のブラウジングから開発まで、マウスを出さずに一台で済ませたい。声を出せるときは音声入力が中心だけれど、深夜や人の多いオフィスでは、キーだけで一日仕事ができる。ゲームは引き続きZENAIMで遊ぶ。

Omnisで大事にしたい「質感」には、アルミの重みや、机に置いて眺めたくなる外観も、思ったとおりに自分の手足のように操作できることも含まれる。最初のケースで確かめたいのは、**小人キーでいちばん楽な姿勢のまま、揺れや角度のずれを気にせず打てるか**。

## 手元のキーボードから持ってきたいもの

| キーボード | 気に入っているところ | Omnisに向けて |
| --- | --- | --- |
| Lofree Flow 2 | 薄くミニマルな佇まい、アルミの重さ、ガスケットマウントの打鍵感。 | 標準ピッチは広く、使わないキーも多い。自宅で使うと1週間弱で充電が必要になり、そのたびに机にケーブルが出るのが不満。 |
| LaraPad Gen2 | 出社時はノートPCを左右から挟める。入力もポインティングも手元で完結する。 | 持ち歩くには大きく、ケースの丈夫さも物足りない。タップからドラッグに移る操作は好きだが、狙った位置に合わせにくい。2本指スクロールは滑りが好みでない。 |
| 小人キー（17 mmピッチ版） | 指の長さに沿った配列と、左右を立てた姿勢がいちばん手に合う。右でカーソルを動かし、左のボールを転がすだけでスクロールできる。 | ヒンジが打鍵で揺れ、角度も少しずつ変わる。ここが安定すれば理想にかなり近い。センサーのはんだ付けが難しく、球を動かしても細かな動きにカーソルがついてこないことがある。 |
| ZENAIM | 軽い押し始め、角の立った輪郭、アルミの仕上がり。見た目も仕事で使いたいと思える理由の一つ。 | 打鍵音はほどよく、押した感覚が残ればよい。ラピッドトリガーはゲーム用で足りている。 |

## ケースで再現したい姿勢と形

小人キーはいつも、立てられる上限まで立てて使う。手のひらが机に対して起きるほど楽で、もう少し立ててみたいくらい。「45度くらい」は体感なので、試作の基準には手元の小人キーの実際の傾きを使う。家でも左右を離して使いたい。一体型で気に入っていたのは打鍵感と、置いた位置を直さずに済む堅牢さ。左右の連結や無段階の角度調整は、今のところ必須ではない。

以前に試した固定角度のケースは、傾斜を支える部分にフィラメントを多く使い、見た目も重たくなった。Omnisでは薄さや小ささを競う必要はない。大きめの球を載せて片側が厚くなっても、輪郭がすっきりしていればよい。持ち運んでも壊れにくいことは大事で、収納時に平らに畳めることの優先度はそれより低い。

| 操作する場所 | 試作で見たいこと |
| --- | --- |
| 文字キーと親指キー | 17 mmピッチ。上から見て中指の列は奥、小指の列は手前にずらす。いつもの角度で文字キーに手を置いたとき、左右の親指がそのままSpaceとEnterに乗るか。 |
| 右手のポインティング | 手は少し動いてもよい。無理のない姿勢で数文字を狙って選び、目的の位置へドラッグできるか。小人キーの、球を操作すると人差し指の下のキーでクリックできる使い方が比較の基準。大きめの球は試したい候補で、キーキャップ型のトラックパッドにも関心がある。 |
| 左手のスクロール | 縦スクロールをすぐに使いたい。専用ホイールは未体験。AとCの外観案では、右の球と左右対称になるよう、左の手前内側にホイールを置いてみる。まずはSpaceから左親指を移して回せるか、Spaceを押すときにホイールまで触れてしまわないかを確かめたい。以前の候補は、手前の側面を親指で回す位置と、右側面を人差し指で回す位置。横スクロールの頻度は低い。 |
| 音声入力キー | 話し始めるときは両手が膝の上にあることが多い。左手を伸ばし、ユニットの端を指一本で押せるか。短押しで開始・終了、長押しで押している間だけ入力する操作が好み。 |

## キーを減らしても、一日仕事ができる配列

ファンクション列、独立した数字列と矢印キー、右端のDelete・Home・End・Page Up・Page Down、Caps Lockは省きたい。矢印はレイヤー上のI・J・K・L付近で使えればよい。

数字と記号はLaraPadの配列が手になじんでいる。左Spaceを押し続けると、左手側の上の段に0〜5、その下に6〜9が並ぶ。右Enterを押し続けると、同じ位置で記号を打てる。英語と日本語を文字キーの同時押しで切り替える操作も残したい。チルダやバックスラッシュなど、たまに使う記号は見失いやすい。今もMacのメニューバーからLaraPadの配列を確認できるようにしていて、Omnisでも配置を見ながら覚える方法でよい。

音声入力キーには、各自が使うアプリのショートカットを割り当てたい。現在のAqua Voiceでは、Control＋Optionの長押しで押している間だけ入力し、Control＋Option＋Spaceで連続入力を開始・終了する。

## 無線・電源とMac／Windowsの切り替え

机にケーブルを出さずに使いたい。仕事で毎日使って、電池交換が月1回程度で済めばうれしい。交換式の単三電池が候補で、消費電力とサイズが許せばボタン電池も試したい。電池の種類と実際の持ちは未確定。

自宅はMac、オフィスではMacとWindowsを頻繁に切り替える。接続先は手元で切り替え、コピーなどはどちらでも同じ位置で押したい。記号もOmnis上ではUS配列どおりに打てるのが希望。Windows側の設定を変えた結果、内蔵キーボードもUS配列になることは許容できる。

## 最初の試作

まず3Dプリンターでケースを繰り返し作り、空中配線でも普段の操作ができるところまで持っていく。使ってみて分かったことを次の形に反映する。進め方の案は次のとおり。

1. 左右のプレートにスイッチとキーキャップを挿す。小人キーに近い傾きと、それより少し立てた傾きで同じ文章を打ち、揺れと親指の位置を比べる。プレートと傾斜台を別に作れば、角度だけを試し直せる。
2. 手に合った形を仮配線して仕事で使う。文章入力、Spaceを押しながらの数字入力、膝から左手を伸ばしての音声入力を試す。有線でも、この段階の打ちやすさは確認できる。
3. ボールとホイールを仮置きし、指の届き方を比べる。実際に動かす段階では、数文字のドラッグと、長いページを読んでから打鍵に戻る操作を試す。球径やセンサー、ホイールの位置はその結果を見て決める。
