# Omnis

Omnisは、コンセプトの検討から始める自作キーボードです。基板、ケース、ファームウェアをこのリポジトリで一緒に管理します。

[コンセプトの検討メモ](docs/concept.md) · [A案のケースを印刷する](case/a/README.md)

| ディレクトリ | 管理するもの |
| --- | --- |
| [pcb/](pcb/) | 回路図、基板レイアウト、部品表、製造用データ |
| [case/](case/) | ケースやプレートの設計ファイル、加工・出力用データ |
| [firmware/](firmware/) | ファームウェアのソース、基板設定、キーマップ |
